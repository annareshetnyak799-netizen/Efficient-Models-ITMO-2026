# HW-2 - Data Diet

Частичное воспроизведение статьи **Deep Learning on a Data Diet**: небольшая CNN на CIFAR-10, сравнение полного датасета, случайных 50% и 50%, выбранных по EL2N. Три независимых повтора, по 8 000 шагов на итоговую модель.

## Запуск

Открыть `data_diet_colab.ipynb` в Google Colab, включить GPU и выполнить ячейки по порядку. Подключить Google Drive для сохранения результатов и продолжения после отключения. Используются библиотеки Colab, версии записаны в `results/environment.json`.

## Результат

Средняя тестовая точность ± выборочное стандартное отклонение:

| Данные | Точность, % |
|---|---:|
| Все данные | 88,36 ± 0,27 |
| Случайные 50% | 86,50 ± 0,27 |
| EL2N 50% | 87,12 ± 0,52 |

EL2N в среднем лучше случайного отбора на 0,62 п.п., но уступает полному датасету на 1,24 п.п. Преимущество наблюдалось в двух повторах из трех. Ограничения описаны в отчете.
